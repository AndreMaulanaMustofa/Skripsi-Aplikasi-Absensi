<h3>GeoScan Attendance App</h3>
<p>This repository contains the code for the GeoScan Attendance mobile application, designed for students to easily scan QR codes for attendance. The app features GPS geofencing to verify physical presence, ensuring accurate attendance tracking. This solution enhances the attendance management process for both students and administrators.</p>
